# The only runtime dependency. Everything else is stdlib on purpose (build plan
# §0.6 — ask before adding a dependency).
#
# psycopg 3, not psycopg2: current and maintained rather than in maintenance
# mode. The [binary] extra ships a prebuilt wheel, so installing needs no C
# compiler — without it, `pip install` on Windows fails with compiler errors.
#
# Pinned exactly. GitHub Actions installs this frozen; an unpinned driver that
# silently upgrades mid-season is an outage in a pipeline whose whole value is
# uninterrupted uptime.
psycopg[binary]==3.3.4

# Transitive closure, audited 2026-08-11. `pip install -r` resolves
# dependencies-of-dependencies at install time, so a single top-level pin is not
# a frozen install — and the step in ingest.yml calls itself "Install frozen
# dependencies", so that claim has to be true. On Python 3.13 the closure of
# psycopg[binary] is three packages:
#
#   psycopg-binary       pinned to ==3.3.4 by psycopg's own metadata, so it
#                        cannot drift while the line above is pinned. Not
#                        repeated here; a second copy of the number is one more
#                        thing to forget to bump.
#   typing-extensions    required only for python_version < "3.13", and the
#                        runner and this laptop are both 3.13, so it is not
#                        installed. Do not add it — that installs a package the
#                        marker deliberately excludes.
#   tzdata               required only on win32, i.e. locally and never on the
#                        ubuntu runner. Unpinned upstream, which makes it the one
#                        genuinely floating dependency. Pinned below with the
#                        same marker psycopg uses, so Linux installs are
#                        unchanged.
tzdata==2026.1; sys_platform == "win32"
